# 🧠 Omniverse Tool Memory & Sensory Learning Protocols

This protocol mandates persistent memory recording of all autonomous tool operations, debugging reflections, and sensory research across the workspace.

---

## 1. Scratchpad Virtualization Invariant
- Any tool invocation producing more than 10 lines of raw output MUST be virtualized into `.scratchpad/`.
- The agent receives only a `VirtualLogDigest` (`status`, `exit_code`, `head_preview`, `log_reference_path`).
- Use `grep_scratchpad(log_path, pattern)` and `read_slice(log_path, start, end)` to inspect specifics without token bloat.

---

## 2. Self-Healing Terminal & CLI Learnings
- Whenever a terminal command fails and is successfully resolved through automated reflection, the fix MUST be appended to `.agents/logs/tool_learnings.md`.
- Subsequent invocations of similar tasks MUST reference `tool_learnings.md` before executing new shell commands.

---

## 3. Autonomous Research Ingestion
- All YouTube and web intelligence generated by `Omniverse/research_pod/` MUST be persisted as structured markdown dossiers in `.agents/context/research_briefs/{topic_slug}_research_brief.md`.
- Dossiers MUST contain video chapter timestamps, key takeaways, and source attribution links.
