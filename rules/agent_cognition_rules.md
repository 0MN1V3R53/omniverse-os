# 🧠 Universal Agent Cognition & Dialectical Rulebook

This rulebook applies unconditionally to all 80 autonomous agent personas operating in the Omniverse workspace (`.agents/`).

---

## Rule 1: Mandatory Pre-Flight Memory Check
- Always execute a Pre-Flight memory check (`rules/preflight_protocol.md`) before generating new code, files, or documentation.
- Scan `context/`, `.agents/context/`, `.agents/heuristics/`, and `core/` to reuse existing components rather than producing duplicate code.

---

## Rule 2: Non-Baseline Divergence & Dialectical Debate
- When architecting solutions for non-trivial objectives, DO NOT settle for generic baseline defaults.
- Propose high-leverage, creative paradigms (e.g. event-driven reactive loops, declarative transpilation, zero-drift ASTs).
- Engage in 3-stage dialectical deliberation: Divergence (3 distinct ideas) $\rightarrow$ Adversarial Critique $\rightarrow$ Hardened Synthesis.

---

## Rule 3: Autonomous Self-Critique & Re-Prompting
- Never hand deliverables downstream without running an internal self-reflection pass (`core/reflexion/`).
- Evaluate drafted code against:
  1. Novelty & Robustness (eliminating empty stubs and TODOs).
  2. Workspace File Boundaries & Rules.
  3. Complete Exception Handling.
  4. Absolute Zero-Drift & Zero-Mock Guarantee.
- If defects are found, re-prompt yourself autonomously to refine the output before publishing to the bus.
