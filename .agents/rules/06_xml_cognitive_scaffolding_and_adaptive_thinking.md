# RULE 06: XML COGNITIVE SCAFFOLDING & ADAPTIVE THINKING ENGINE

## 1. Structured XML Cognitive Namespace Protocol
1.1 Derived from frontier prompt architectures (Claude Mythos 5 / Opus 4.8 / DeepSeek V4), all agent reasoning, verification passes, and state tracking MUST be demarcated using explicit, structured XML namespaces.
1.2 XML tags provide mathematically superior instruction adherence over plain Markdown headers by preventing instruction drift across high-entropy context windows.
1.3 Every agent thought trace and review pass must utilize the following structured blocks:
    - `<cognitive_state>`: Current execution phase, active task ID, memory registers, and target file boundaries.
    - `<scratchpad_reasoning>`: Uncensored, unfiltered stream-of-consciousness logic, AST trace prediction, and intermediate hypothesis testing.
    - `<pre_flight_check>`: Verification of dependencies, file paths, imports, and interface signatures prior to invoking file-editing tools.
    - `<confluence_audit>`: Post-generation diff auditing ensuring zero regression against `.agents/context/` blueprints.

2.1 All task delegations from CEO Dr. Alexander Vance and Pod Leads must be structured according to the Context Sandwich Protocol to maximize recall across 1M-token context windows:

## 3. Always-On Adaptive Compute Scaling
3.1 Agents must dynamically scale test-time reasoning depth based on task complexity without requiring manual budget flags:
    - **Low Entropy (Simple Fixes / Formatting)**: Direct `<pre_flight_check>` -> minimal scratchpad -> instant execution.
    - **High Entropy (Cryptographic Ratchet / SQLCipher DB Migration / Web3 Smart Routing)**: Exhaustive `<scratchpad_reasoning>` with multi-path hypothesis evaluation, race condition modeling, and memory zeroization proofs.
3.2 If an invariant breach or logic contradiction is encountered during scratchpad evaluation, the agent must immediately log the anomaly within `<scratchpad_reasoning>` and execute an autonomous pivot before generating code.
