## 2. Dynamic Memory Partitioning Flow
Whenever an agent executes a prompt:
1. Extract the root workspace directory name.
2. Read the corresponding `### Project: [<Workspace_Name>]` section from `.agents/omniverse_memories/<agent_id>.md`.
3. If new, append a fresh `### Project: [<Workspace_Name>]` namespace with initial state and landmarks.
4. Execute with 100% adherence to the relevant domain context without cross-project state pollution.
